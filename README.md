# Qwen Documentation

This is the source of the documentation at [<https://qwen.readthedocs.io>](https://huggingface.co/Qwen/Qwen3-0.6B).

## Git Clone

```bash
git clone https://github.com/1pod-x/llm-project-LisaShan.git
cd llm-project-LisaShan
```

## Create a Virtual Environment

 named qwen3 by running
```bash
python -m venv qwen3
source qwen3/bin/activate
```

## Install Dpendencies

```bash
pip install -r requirements-docs.txt
```

## Transformer Installation

According to https://huggingface.co/docs/transformers/installation

Python

 ```bash
pip install transformers
 ```

Source Install:
 ```bash
 pip install git+https://github.com/huggingface/transformers
 ```

Editable Install: 
 ```bash
git clone https://github.com/huggingface/transformers.git
cd transformers
pip install -e .
```
